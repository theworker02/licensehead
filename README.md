Scan .js and .ts files for SPDX-License-Identifier and report files that are missing a header.

## Install

```bash
git clone https://github.com/theworker02/licensehead.git
cd licensehead
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
licensehead [dir]
```

Source: `main` branch, `/docs` folder. Enable Pages, then open `https://theworker02.github.io/licensehead/`.
